GURUKUL CLASS-X WEBSITE — UPLOAD GUIDE

1. Upload the contents of this Class-X folder to your GitHub repository.
2. Keep logo.png in the same folder as index.html, home.html, and presentation.html.
3. The supplied logo.png is the current school logo. You can replace it later with your own file, keeping the exact name: logo.png
4. Keep the ppts folder structure. Add future HTML presentations inside ppts/<Subject Name>/.
5. The library.js file discovers presentations from the GitHub repository.
6. Main entry page: index.html

Important: Do not rename logo.png unless you also update the image paths in the HTML files.
